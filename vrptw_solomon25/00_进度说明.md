## 4. 关键经验（本家族踩过的坑）

1. Git Bash 调 WSL 必须 MSYS_NO_PATHCONV=1（/mnt/d 会被误转 Windows 路径）。
2. 次梯度必须是覆盖次数 1−Σa·x（布尔标志会让 λ 卡死在错误点，L≈−5×10⁴）。
3. 次梯度步长 (UB−L)/‖g‖² 在 ‖g‖→0 时发散 → 步长与 λ 双重截断。
4. CP-SAT 定价接受判定必须用双精度精确 rc（整数缩放有 0.0125/列 误差）。
5. 强制弧节点初始列集为空会使 Σx≥K_lb 不可行 → 需以含强制弧的池列播种。
6. mathopt：无 inf 常量；time_limit 必须传 datetime.timedelta；dual_values 以约束对象为键。
7. 精确最优 191.8136197787：6 位小数 191.813620 与两位小数 191.81 是同一值的不同舍入。
